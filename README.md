# PV Vaishak | Premium Luxury Taxi Service

A professional, high-end, and visually engaging single-page website built for a premium luxury taxi service. The website is designed to build trust, showcase the vehicle and driver, and make it incredibly easy for potential customers to book a ride.

## Features

- **Modern & Luxurious Design:** Uses a sleek glassmorphism aesthetic with a dark/light elegant contrast and gold accents to convey a premium feel.
- **Dynamic Video Background:** Features an immersive looping background video that instantly grabs attention without being distracting.
- **Responsive Layout:** fully optimized for desktop, tablet, and mobile devices.
- **Interactive Animations:** includes custom cursor glow effects, smooth scroll animations, a looping typewriter effect for the driver introduction, and an infinite scrolling marquee.
- **Quick Booking:** Strategically placed "Book Now" buttons and a detailed contact card next to the driver's profile to maximize conversions.
- **Service Highlights:** Clear presentation of the "Why Choose Us" features with beautifully animated SVG icons.

## Technology Stack

- HTML5
- CSS3 (Vanilla CSS, no external frameworks)
- JavaScript (Vanilla JS for animations and interactions)
- Google Fonts (Outfit & Playfair Display)

## Project Structure

- `index.html`: The main HTML document containing the structure of the website.
- `style.css`: The stylesheet defining the layout, design system, responsive media queries, and CSS animations.
- `script.js`: The JavaScript file handling the Intersection Observer (for scroll animations) and the custom typewriter effects.
- Assets:
  - `background.mp4`: The looping video background.
  - `driver.jpg`: The profile photo of the driver.

## Setup & Deployment

Since this is a static website, no build process or dependencies are required. 

1. Clone or download the repository to your local machine.
2. Open the project folder.
3. Double-click `index.html` to open it in your default web browser, or serve it using a local development server (e.g., Live Server extension in VS Code) to ensure the video background loads properly.
4. To deploy, simply host the files on any static hosting provider (e.g., GitHub Pages, Netlify, Vercel, or standard cPanel hosting).

## Customization

- **Colors:** The primary colors are defined as CSS variables at the top of `style.css` (`--gold`, `--glass-bg`, etc.). You can easily change these to match your brand.
- **Text & Details:** Open `index.html` to update the contact details, name, and descriptions.
- **Media:** Replace `background.mp4` and `driver.jpg` with your own assets. Make sure to keep the filenames the same or update the references in the HTML file.
